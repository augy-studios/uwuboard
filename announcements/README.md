# Announcements

What's said about each release, one file per kind and version, as written:

| File | Where it goes |
|---|---|
| `release-notes-<version>.md` | The GitHub release's description (release/README.md, "Put it on GitHub"). Its first paragraph is the summary. The Android app's Updates page shows that, and under `## What's new` (or `What's fixed`) a card for each `###` heading with its `- **Title**: text` lines, so keep to that shape |
| `announcement-<version>.md` | The UwU Apps Telegram channel, pasted as it is. Short lines, no Markdown: Telegram shows it plain |
| `play-release-notes-<version>.md` | Play Console's **Release notes** box, the block inside the code fence (GOOGLE-PLAY.md) |

Write all three for a release of the apps; a release that changes only the website needs just
the announcement.
