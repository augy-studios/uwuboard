# Google Play release notes, 1.0.2

Paste the block below into the release's **Release notes** box in Play Console (GOOGLE-PLAY.md,
section 10). Play allows 500 characters per language; this is about 155.

```text
<en-GB>
What's new in 1.0.2:
• Report a bug, from the edge tray
• Screenshot the whole page with the bug, top to bottom
• A report ID to quote once it's sent
</en-GB>
```

The Google Play build has no Updates page of its own (Play updates it), so its notes leave that out.
